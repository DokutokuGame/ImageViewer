# ImageViewer v0.1.1 发布说明

## 版本与产物

Python 项目、根 Node/Electron 应用、历史 Electron 原型与本说明统一使用 `0.1.1`。
Windows 发布产物为 `ImageViewer-0.1.1-win-x64.zip`，同目录的 `.sha256` 文件记录
SHA-256。它是免安装便携包；解压到新目录即完成安装，运行 `ImageViewer.exe` 启动。
下载页面：[GitHub Release v0.1.1](https://github.com/DokutokuGame/ImageViewer/releases/tag/v0.1.1)。

## 可复现构建与验证条件

- 提交：以工作流日志中的完整 Git SHA 为准；
- 干净环境：GitHub 托管 `windows-2025` x64 镜像，不复用工作区；
- 工具链：Node.js `20.18.1`、npm 锁文件、Electron `41.7.1`；
- 命令：依次运行 `npm ci`、`npm run build:windows`、`npm run verify:windows`；
- 检查：重新计算 SHA-256，在全新临时目录解压，确认 `ImageViewer.exe` 存在，且包内
  应用清单版本为 `0.1.1`，并确认项目、Electron、Chromium 和第三方通知文件齐全；
- 证据：`Windows release package` 工作流日志与保留 14 天的 artifact。

2026-08-04 的本地 Windows x64 验证还包括从全新解压目录启动 `ImageViewer.exe`，进程持续
运行五秒且没有立即崩溃。该冒烟测试不替代真实媒体操作、长期稳定性或跨平台验证。
当前只发布 Windows x64 便携包；程序未签名，Windows SmartScreen 可能显示未知发布者提示。

## v0.1.1 更新

- 默认使用英文界面，并保留完整的简体中文翻译字典；
- 静态控件、无障碍标签、动态状态、对话框和媒体加载反馈统一通过国际化层输出；
- 英文 README 成为默认项目入口，同时提供简体中文版。

## 已有能力

- 扫描本地媒体目录并分页浏览缩略图；
- 应用内图片预览及前后导航；
- 保存根目录偏好并按目录筛选；
- 实验性的 Python SQLite 索引与自动标签组件。

## 安全与隐私

发布包不包含真实媒体、用户路径、数据库、密钥或本地日志。包根目录包含项目 MIT License、
Electron License、Chromium notices 和 `THIRD_PARTY_NOTICES.txt`。校验下载文件时，在
PowerShell 中运行 `Get-FileHash .\ImageViewer-0.1.1-win-x64.zip -Algorithm SHA256`，
并与 `.sha256` 文件首列逐字比较。
