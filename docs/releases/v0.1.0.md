# ImageViewer v0.1.0 候选发布说明

## 版本与产物

Python 项目、根 Node/Electron 应用、历史 Electron 原型与本说明统一使用 `0.1.0`。
Windows 候选产物为 `ImageViewer-0.1.0-win-x64.zip`，同目录的 `.sha256` 文件记录
SHA-256。它是免安装便携包；解压到新目录即完成安装，运行 `ImageViewer.exe` 启动。

## 可复现构建与验证条件

- 提交：以工作流日志中的完整 Git SHA 为准；
- 干净环境：GitHub 托管 `windows-2025` x64 镜像，不复用工作区；
- 工具链：Node.js `20.18.1`、npm 锁文件、Electron `26.2.4`；
- 命令：依次运行 `npm ci`、`npm run build:windows`、`npm run verify:windows`；
- 检查：重新计算 SHA-256，在全新临时目录解压，确认 `ImageViewer.exe` 存在，且包内
  应用清单版本为 `0.1.0`，随后删除临时目录；
- 证据：`Windows release package` 工作流日志与保留 14 天的 artifact。

验证只证明该提交可在上述环境生成并解压候选包，不代表已测试图形界面启动、真实媒体、
Windows 其他版本/架构、代码签名、自动更新或长期稳定性。发布仍受许可证确认阻断。

## 已有能力

- 扫描本地媒体目录并分页浏览缩略图；
- 应用内图片预览及前后导航；
- 保存根目录偏好并按目录筛选；
- 实验性的 Python SQLite 索引与自动标签组件。

## 安全与隐私

候选包不应包含真实媒体、用户路径、数据库、密钥或本地日志。校验下载文件时，在
PowerShell 中运行 `Get-FileHash .\ImageViewer-0.1.0-win-x64.zip -Algorithm SHA256`，
并与 `.sha256` 文件首列逐字比较。
